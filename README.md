# 🚖 Cab Booking System Analytics (SQL Project)

A SQL-based project that simulates a real-world cab booking platform and demonstrates how SQL can be used to generate business insights from operational data.

---

## 📌 Project Overview

This project models a cab booking system using a relational database. It includes customers, drivers, cabs, bookings, trip details, and feedback data.

The goal of this project is to analyze ride operations, customer behavior, driver performance, cancellations, and revenue trends using SQL queries.

---

## 🎯 Objectives

- Design a relational database using MySQL
- Implement Primary Keys and Foreign Keys
- Manage customer and booking data efficiently
- Analyze customer booking behavior
- Evaluate driver performance
- Track revenue and business growth
- Generate meaningful business insights
